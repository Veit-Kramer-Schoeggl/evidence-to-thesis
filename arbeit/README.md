# Die Arbeit selbst

Hier liegt der Text der Arbeit: LaTeX oder Word, wie es deine Hochschule
verlangt.

**Vorlagen der Hochschule sind nicht enthalten.** Hol sie dir über die
offiziellen Kanäle deines Studiengangs und leg sie hier ab. Ob sie in ein
öffentliches Repository dürfen, klärst du mit deiner Hochschule; im Zweifel
bleibt das Repository privat.

Die Bibliografie liegt im Wurzelordner als `literatur.bib`. Aus LaTeX bindest
du sie relativ ein, etwa mit `\bibliography{../literatur}`.

Zahlen kommen nicht von Hand in den Text, sondern aus den Auswertungen, dem
Register (`data/register.yaml`) oder aus erzeugten Blöcken deiner Rechnungen.
